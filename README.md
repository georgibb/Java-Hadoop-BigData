# Hadoop Environmental Expenditure Analyzer

Курсов проект по **Big Data**.

Java приложение с **Apache Hadoop (MapReduce)** и **GUI интерфейс** за анализ на разходите за опазване на околната среда по:
* **година (year)**
* **сектор (sector)**
* **единици на измерване (units)**

Приложението поддържа:
* комбинирано филтриране на данните;
* изчисляване на **обща стойност** на разходите (`data_value`);
* изчисляване на **средна стойност** според зададените филтри и колоната `Flag`.
